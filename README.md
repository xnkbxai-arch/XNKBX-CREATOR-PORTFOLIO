# XNKBX Creator Portfolio

Static portfolio website ready for Vercel. All site media and fonts are bundled in `assets/`.

## Build

```sh
npm run build
```

The build validates local asset references and writes the deployable website to `dist/`. In Vercel, import this repository; `vercel.json` configures the build command and output directory.

The Shaperr video starts on click, with native controls. The other case videos are YouTube embeds and have links to open directly on YouTube.
